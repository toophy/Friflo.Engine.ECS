# 对齐 AoS 显式启用

Status: accepted

2026-10-08 用户确认以 main 的既有调用兼容性为本次整合门槛。misakaruntime 的 SoA 历史会仅凭单个浮点或向量 value 字段自动选择带起始偏移的对齐存储；这种存储无法同时提供 main 原来的可写、从组件索引零开始的 T[] 数组语义。未标注组件因此保留普通 AoS；对齐 AoS 通过 `[AoSAligned]` 显式选择，原有 `[SoA]` 和 `[AoSoA]` 能力保留。

旧 Chunk 数组字段、SIMD 方法和向量扩展恢复普通布局语义。新布局使用其专用访问 API，不返回伪造或脱离实体状态的数组副本。已有对齐测试改为显式选择布局，仍验证相同的对齐、扩容和访问要求。后续测量须基于这个整合结果；来源分支的旧性能数字不能直接视为修改后的性能。
